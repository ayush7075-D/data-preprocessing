# Simple Data Preprocessing

## Introduction

This project demonstrates basic data preprocessing using Python.

A small student dataset is used for demonstration. The data contains student names, ages, genders, and marks.

## Dataset

The dataset contains the following information:

- Name
- Age
- Gender
- Subject 1 Marks
- Subject 2 Marks

## Data Preprocessing Steps

The following preprocessing operations are performed:

### 1. Display Original Data

The original student data is displayed before preprocessing.

### 2. Remove Duplicate Data

The program checks for duplicate rows and removes them.

### 3. Convert Categorical Data

The Gender column contains categorical values:

- Male
- Female

These values are converted into numerical values:

- Male = 0
- Female = 1

### 4. Display Preprocessed Data

After preprocessing, the cleaned data is displayed on the screen.
